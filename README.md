Project: Notes App

Build a simple Notes Application using React.

⸻

Requirements

1. Add Notes

User should be able to:

* Add a note title
* Add note description
* Save the note

⸻

2. Display Notes

* Show all added notes in card format
* Each card should contain:
    * Title
    * Description
    * Created time

⸻

3. Delete Notes

* User can delete any note

⸻

4. Edit Notes

* User can update existing note data

⸻

5. Search Notes

* Search notes by title

⸻

6. Notes Counter

Display:

* Total notes count
* Filtered notes count

⸻

7. Input Focus

* Input should automatically focus when page loads

⸻

8. Expensive Calculation Demo

Create one section:

* Count total characters from all notes
* Show the value in UI

Application should remain smooth while typing/searching.
